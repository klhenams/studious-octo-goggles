# Security Policy

## Supported Versions

Security updates are typically applied to the latest version of the main branch.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report the issue privately to the repository maintainers by opening a confidential report through GitHub's private vulnerability reporting feature if available, or by contacting the repository owner directly.

Please include:

- a description of the vulnerability
- the affected version or branch
- steps to reproduce the issue
- any suggested mitigation

We will review the report and coordinate a fix as quickly as possible.
