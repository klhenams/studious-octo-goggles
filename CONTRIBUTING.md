# Contributing

Thanks for helping improve this project.

## Getting Started

1. Fork the repository and create a branch from `main`.
2. Install the local development environment using the instructions in [README.md](README.md).
3. Make your changes and add or update tests where appropriate.
4. Run the relevant checks before submitting a pull request.

## Development Workflow

- Keep changes focused and easy to review.
- Follow the existing Django and Python style used in the project.
- Prefer small, well-documented commits.
- Add tests for behavior changes when feasible.

## Pull Requests

- Open a pull request with a clear summary of the change.
- Include context for any bug fix, feature, or refactor.
- Mention any related issues or follow-up work.

## Reporting Issues

Please search existing issues before opening a new one and include as much detail as possible, including steps to reproduce the problem.
